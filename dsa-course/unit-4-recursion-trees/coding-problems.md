# Unit IV Coding Problems

## 1. Recursive number problems

Implement recursive factorial, power, sum of digits, and greatest common divisor. For every function, identify the base case and recurrence.

## 2. Tower of Hanoi

Print the minimum sequence of moves for `n` disks. Also print the total count, which must be `2^n - 1`.

## 3. Binary tree construction and traversal

Build a binary tree from a preorder sequence containing `-1` for null nodes. Print in-order, pre-order, post-order, and level-order traversals.

## 4. Tree height, size and diameter

Return the height, number of nodes, number of leaves, and diameter of a binary tree. Aim for `O(n)` time for diameter instead of recalculating every subtree height.

## 5. Check whether two trees are identical

Given roots of two binary trees, return true only when their shapes and values are identical.

## 6. Validate and operate on a BST

Implement search, insertion, deletion, minimum, maximum, and validation for a binary search tree. Test deletion for a leaf, one-child node, and two-child node.

## 7. Lowest common ancestor

Find the lowest common ancestor of two values in a BST. Use the ordering property to solve it in `O(h)` time.

## 8. Sorting with recursion

Implement merge sort and quick sort. Print the number of comparisons and explain average and worst-case complexity for both algorithms.
