# Unit IV Problems

## 1. Recursive factorial and Fibonacci

**Type:** Basic recursion

Write both functions with clear base cases. Compare naive Fibonacci, which repeats work, with an iterative or memoized version.

## 2. Tower of Hanoi

**Type:** Recursion and recurrence

Move `n` disks between three rods without placing a larger disk on a smaller one. The minimum number of moves is $2^n - 1$.

## 3. Tree traversals

**Type:** Binary tree traversal

Build a binary tree and print recursive in-order, pre-order, and post-order traversals. Add level-order traversal using a queue.

## 4. Height and leaf count

**Type:** Tree recursion

Return the height of a binary tree and count nodes with no children. An empty tree has height `0` under the node-count definition.

## 5. Validate a BST

**Type:** Tree property checking

Do not only compare each node with its direct children. Carry a valid lower and upper bound through recursion. Complexity: `O(n)` time.

## 6. BST insert, search and delete

**Type:** Ordered tree operations

Implement deletion for a leaf, a node with one child, and a node with two children. For two children, replace with the in-order successor or predecessor.

## 7. Merge sort and quick sort

**Type:** Divide and conquer

Implement both algorithms and compare their average time, worst-case time, stability, and extra memory requirements.
