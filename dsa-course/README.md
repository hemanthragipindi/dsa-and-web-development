# CSE205 Data Structures and Algorithms

This folder follows the syllabus shown in the course outline.

| Unit | Folder | Main topics |
|---|---|---|
| I | `unit-1-arrays-searching` | Complexity, arrays, sorting, searching |
| II | `unit-2-linked-lists` | Singly, doubly, circular and header lists |
| III | `unit-3-stacks-queues` | Stacks, expressions, queues and deques |
| IV | `unit-4-recursion-trees` | Recursion, binary trees, BST and sorting |
| V | `unit-5-heaps-hashing` | Heaps, heapsort and hashing |
| VI | `unit-6-graphs` | BFS, DFS and shortest paths |

Every unit has:

- `concept.md`: definitions, operations and complexity notes.
- `problems.md`: different problem patterns with explanations and examples.
- `coding-problems.md`: implementation questions with input, output, edge cases, and target complexity.
- `cpp/`: runnable C++ programs grouped by the topics in that unit.

Recommended order: read the concept file, solve the problem without looking at the explanation, then compare your approach and complexity.
