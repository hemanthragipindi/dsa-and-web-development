# Unit VI Coding Problems

## 1. Safe division

Write a function that divides two numbers and throws a meaningful exception when the denominator is zero. Catch it in `main`.

## 2. Custom exception

Create an `InsufficientBalance` exception for a bank account. Throw it when a withdrawal would make the balance negative.

## 3. Function template

Write a template function to return the maximum of two values and test it with integers, doubles, and strings.

## 4. Class template stack

Implement a fixed-capacity `Stack<T>` template with `push`, `pop`, `top`, overflow, and underflow handling.

## 5. STL vector algorithms

Read numbers into a vector, remove duplicates, sort them, find a target, and print the frequency of each value using STL algorithms.

## 6. STL container comparison

Store the same values in a `vector`, `list`, and `set`. Demonstrate insertion, traversal, sorting behavior, and duplicate handling.

## 7. Generic record sorting

Create an `Employee` structure and sort a vector by salary and then by name using comparator functions or lambdas.
