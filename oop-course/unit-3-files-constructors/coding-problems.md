# Unit III Coding Problems

## 1. Student record file

Write student records to a text file, then read them back and print only students whose marks are above a given threshold.

## 2. Sequential and random access

Store fixed-size employee records in a binary file. Read the record at a requested index using `seekg` without reading all previous records.

## 3. Constructor variations

Create a `Rectangle` class with a default constructor, parameterized constructor, copy constructor, and destructor. Print messages to observe object lifetime.

## 4. Deep-copy class

Create a class that owns a dynamic character buffer. Implement a copy constructor that allocates independent storage. Prove that changing one object does not change the copy.

## 5. Constructor delegation

Create a `Date` class with a default constructor delegating to a parameterized constructor. Validate day, month, and year before storing them.

## 6. File word statistics

Read a text file and count lines, words, characters, and digits. Report a useful error when the file cannot be opened.
