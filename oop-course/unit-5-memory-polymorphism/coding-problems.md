# Unit V Coding Problems

## 1. Dynamic matrix

Create a dynamically allocated matrix, implement input, display, transpose, and cleanup. Ensure every row and the outer pointer are released correctly.

## 2. Rule of three

Create a `StringBuffer` class with a dynamic character array. Implement destructor, copy constructor, and copy assignment operator so copying is deep and safe.

## 3. Abstract shape hierarchy

Create an abstract `Shape` class with pure virtual `area` and `perimeter` functions. Implement `Circle`, `Rectangle`, and `Triangle`.

## 4. Runtime payroll

Store different employee types through `vector<Employee*>` or smart pointers. Use a virtual salary function and print each employee's calculated pay.

## 5. Virtual destructor test

Create base and derived classes with destructors that print messages. Delete a derived object through a base pointer and explain the result with and without `virtual`.

## 6. Self-referential linked node

Create a `Node` class that points to another `Node`. Build, traverse, and safely destroy a list using dynamic memory.
