# Unit II Coding Problems

## 1. Pointer arithmetic

Read an integer array and print every element using a pointer. Find the sum, minimum, and maximum without using array indexing.

## 2. Dynamic integer array

Ask for `n`, allocate an array with `new`, read its values, find the average, then release it with `delete[]`. Handle `n <= 0`.

## 3. Pointer to pointer

Write a function that allocates an integer through an `int**` parameter. Print the value and release the allocated memory exactly once.

## 4. Array class

Create an `IntArray` class that owns a dynamic array. Implement constructors, a destructor, `get`, `set`, and a display function. Explain why copying this class requires a deep copy.

## 5. String analysis

Count vowels, consonants, digits, spaces, and special characters in a line using `std::string`.

## 6. String class operations

Implement functions to reverse a string, test whether it is a palindrome, and find the first non-repeating character. Do not use a second full string for the reverse operation.
