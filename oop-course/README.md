# CSE202 Object Oriented Programming

This folder follows the OOP syllabus shown in the course outline.

| Unit | Main topics |
|---|---|
| I | C++ basics, classes, access control, functions and recursion |
| II | Pointers, references, arrays and strings |
| III | File operations, constructors, destructors and initialization |
| IV | Operator overloading, type conversion and inheritance |
| V | Dynamic memory, virtual functions and polymorphism |
| VI | Exceptions, templates and the STL |

Each unit contains:

- `concept.md`: concise theory and important rules.
- `coding-problems.md`: implementation questions and requirements.
- `cpp/`: runnable C++ examples for the unit topics.
