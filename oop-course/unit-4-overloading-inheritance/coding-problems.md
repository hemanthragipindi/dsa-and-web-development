# Unit IV Coding Problems

## 1. Complex number operators

Create a `Complex` class and overload `+`, `-`, `*`, and `==`. Print results in the form `a + bi`.

## 2. Fraction arithmetic

Overload arithmetic and comparison operators for a `Fraction` class. Reduce every result using the greatest common divisor.

## 3. Conversion operators

Implement conversion from `Time` to minutes and a constructor converting minutes to `Time`. Prevent unwanted implicit conversions where appropriate.

## 4. Employee inheritance

Create a base `Employee` class and derived `Manager` and `Developer` classes. Reuse base data and override a display function.

## 5. Multiple inheritance ambiguity

Create two base classes with the same function name and a derived class. Call each version using scope resolution, then redesign using a virtual base class if the diamond problem appears.

## 6. Constructor order

Build a three-level inheritance hierarchy and print constructor/destructor messages. Explain the order in which base and derived objects are initialized and destroyed.
