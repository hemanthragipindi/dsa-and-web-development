# Unit I Coding Problems

## 1. Student class

Create a `Student` class with private name, roll number, and marks. Add setters with validation, a display function, and a function that returns the grade.

## 2. Static object counter

Create a class that counts how many objects currently exist. Increment in the constructor and decrement in the destructor. Test local objects and objects created in a nested block.

## 3. Function overloading calculator

Overload `area` for a square, rectangle, and circle. Use appropriate parameter types and explain why return type alone cannot overload a function.

## 4. Swap using three techniques

Implement swap by value, swap by pointer, and swap by reference. Demonstrate which versions change the caller's variables.

## 5. Friend function

Create a `Complex` class and a friend function that adds two complex numbers while keeping the data members private.

## 6. Recursive problems

Write recursive functions for factorial, power, sum of digits, and palindrome checking. State the base case and time complexity for each.
